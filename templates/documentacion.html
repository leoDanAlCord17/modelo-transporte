Uso: modelo de transporte

  1. En Transporte indica el número de orígenes y destinos (1–10) y pulsa Generar tabla.
  2. Escribe los costos unitarios en las celdas, la oferta en la columna derecha y la demanda en la fila inferior. Puedes renombrar orígenes y destinos.
  3. Elige el método inicial (Esquina Noroeste, Costo Mínimo o Vogel) y el objetivo (minimizar costo o maximizar beneficio).
  4. Pulsa Resolver. Verás: la solución inicial y su paso a paso, cada iteración MODI (u, v, costos reducidos, celda entrante y ciclo +/−) y la solución óptima con el plan de envíos.
  5. Comparar los 3 métodos muestra el costo inicial de cada método y cuántas iteraciones MODI necesita para llegar al óptimo.

Si la oferta total no coincide con la demanda total, se agrega automáticamente un origen o destino ficticio con costo 0 y se avisa en los resultados.

Uso: modelo de asignación

  1. En Asignación indica filas (agentes) y columnas (tareas) y genera la matriz.
  2. Escribe los costos (o beneficios, si maximizas) y pulsa Resolver.
  3. Se muestran las celdas asignadas, el costo total y cada paso del método húngaro: reducción por filas y columnas, cobertura de ceros con el mínimo de líneas y ajustes.

Reglas y desempates

MétodoRegla de desempate
Costo MínimoMenor costo → mayor cantidad asignable → menor fila → menor columna.
VogelMayor penalización → línea con el menor costo → filas antes que columnas → menor índice. Con una sola fila o columna activa se asigna por costo mínimo.
DegeneraciónSi fila y columna se agotan a la vez, solo se tacha la fila; la columna recibe luego una asignación 0 (básica degenerada). Siempre hay m + n − 1 básicas.
MODIEntra el costo reducido más negativo (empate: menor fila y columna). El ciclo se halla como el camino único en el árbol de celdas básicas. Si varias celdas "−" llegan a 0, sale la primera del ciclo y las demás quedan como básicas con valor 0.
MaximizaciónTransporte: se minimiza −C. Asignación: se minimiza max(C) − C.

API JSON

Toda la comunicación es JSON (Content-Type: application/json).

POST /api/transporte

{
  "costos": [[10,2,20,11],[12,7,9,20],[4,14,16,18]],
  "oferta": [15,25,10],
  "demanda": [5,15,15,15],
  "metodo_inicial": "vogel",        // "noroeste" | "costo_minimo" | "vogel"
  "objetivo": "min",                // "min" | "max"
  "nombres_origenes": ["S1","S2","S3"],          // opcional
  "nombres_destinos": ["M1","M2","M3","M4"]      // opcional
}

Respuesta (resumida):

{
  "balanceado": true, "ficticio": null,
  "inicial": { "metodo": "vogel", "asignacion": [[...]], "basicas": [[i,j],...],
               "costo_total": 475, "pasos": [...] },
  "optimo":  { "asignacion": [[...]], "costo_total": 435, "envios": [...],
               "iteraciones": [ { "u": [...], "v": [...], "costos_reducidos": [[...]],
                                  "celda_entrante": [i,j] | null, "ciclo": [[i,j],...],
                                  "signos": ["+","-",...], "theta": 5,
                                  "asignacion_resultante": [[...]], "costo": 435 } ] },
  "verificacion_scipy": { "costo_total": 435, "coincide": true }
}

POST /api/comparar

Mismo cuerpo que /api/transporte. Devuelve {"metodos": [{"metodo", "costo_inicial", "iteraciones", "costo_optimo"}, ...]}.

POST /api/asignacion

{ "costos": [[15,10,9],[9,15,10],[10,12,8]], "objetivo": "min" }
→ { "asignacion": [[0,1],[1,0],[2,2]], "costo_total": 27, "pasos": [...],
    "verificacion_scipy": { "costo_total": 27, "coincide": true } }

Errores

Los datos inválidos (campos vacíos, negativos, dimensiones incorrectas…) devuelven HTTP 400 con {"error": "mensaje en español"}.
